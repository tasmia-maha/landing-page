# DEVCONF 2026 — Landing Page

A responsive developer conference landing page built with HTML and CSS.

## 📌 Overview

DEVCONF 2026 is a conference landing page designed to showcase a modern developer conference website.

The page includes a navigation bar, conference hero section, speaker profiles, pricing plans, sponsors section, and footer.

## ✨ Features

* Responsive navigation bar
* Conference hero/banner section
* Speaker showcase section
* Multiple pricing plans
* Sponsors section
* Registration call-to-action buttons
* Responsive layout for different screen sizes
* Clean and modern UI design

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/tasmia-maha/landing-page.git
```

### Navigate to the project folder

```bash
cd landing-page
```

### Run the project

Open the `index.html` file in your browser.

No additional dependencies or package installation are required.
